# 使用说明

## 坐标文件与底图

支持 TXT、CSV、Excel，以及粘贴的分隔文本。常见格式包括两列坐标、三列“点名＋坐标”、四列“点名＋坐标＋高程”。高程可留空；导入、编辑、E/N 互换、撤销、项目保存和坐标导出保留已有高程。

CAD X 对应东 E，CAD Y 对应北 N。推荐先打开底图，再导入坐标；自动识别会利用明确表头或底图范围判断 EN / NE。无法可靠区分时会显示样例供选择。也可以在导入顺序中明确指定。

程序内部坐标以米存储。图纸以米为单位时比例为 1；毫米为 1000；厘米为 100。偏移也按米输入：

```text
CAD X = (东 E + 东向偏移) × 比例
CAD Y = (北 N + 北向偏移) × 比例
```

这不是投影或坐标系转换。软件不会根据坐标量级推断坐标系；图纸未声明单位时，使用者需要核对。

“关闭底图 / 打开底图”仅切换显示，保留已加载底图和视角；再次打开无需选择文件。“打开 CAD 底图”用于更换图纸。保存项目和导出 DXF 仍使用已加载的底图。

默认仅显示点位和标注。“连接全部点”适用于确实表示连续线路的点列；普通导入不会根据点名或距离自动猜道路分组。CAD 取点产生的道路及取点段分别处理，避免跨道路连接。

## CAD 取点

1. 在 AutoCAD 打开目标图纸，结束其他正在执行的 CAD 命令。
2. 在软件点击“CAD 取点”，选择对应文档。打开多张图时核对图名和路径；也可选择尚未打开的 DWG/DXF。
3. 填写道路名称、起始编号、标注字高，核对图纸单位，开始取点。
4. 在 CAD 捕捉点位，然后移动鼠标安排标注。左键或空格确认；`[` / `]` 调整箭头，右键或 Esc 取消尚未确认的标注。
5. 等待下一个点时按 Enter 进入道路菜单。按 N 或在菜单直接 Enter，再填道路名称，即可换路。C 返回当前道路。
6. 新道路从 01 开始；重新使用已有道路名称时接在最大编号后。例如道路1已有03，换道路2从01开始，再换回道路1从04开始。
7. 等待点位时 U 撤销当前道路本轮新增点；菜单内先用 C 返回取点，再使用 U。
8. Q 或等待点位/道路菜单内的 Esc 结束全部取点，已确认的点保留。请在 CAD 保存图纸，在软件保存坐标项目。

输入道路名称时留空或 Esc 会取消本次换路，并返回之前的菜单或取点状态。菜单/名称输入阶段使用普通箭头，返回取点恢复原光标。

## 退出后接着取：ZB

第一次从软件“CAD 取点”启动，让软件与当前图纸建立关联。此后保持软件和该 CAD 图纸打开，在 CAD 命令行输入 `ZB`，填写道路名称，即可重新开始。

每次 ZB 都要求填写道路名；留空或 Esc 取消。已有道路接续编号，新道路从01开始；已有点和标注不重复创建。ZB 沿用上轮字高。

软件中的“继续 CAD 取点”按钮可用于调整本轮字高、道路名称或编号。修改坐标、全局设置，切换项目或底图后，旧的续接状态会失效，此时从“CAD 取点”重新选择图纸。

关闭软件、关闭取点图纸或出现无法核实的异常后，也应重新建立取点关联。不要把 N 当成退出取点后可单独使用的 CAD 命令：N 是取点流程内的选项，ZB 才是退出后的入口。

## 保存与恢复

取点时每次确认、换路或撤销都会保留恢复日志。程序的“恢复取点记录”可读取会话目录内的 `recovery.coordproj`，核对日志并补回尚未写进快照的已确认操作。恢复结果另存为项目；原恢复记录保持不变。

默认用户数据位置：

```text
%LOCALAPPDATA%\CoordinateGeneratorV22\picks
%LOCALAPPDATA%\CoordinateGeneratorV22\logs
```

这些目录可能包含用户图纸路径、点位与会话记录，不属于开源项目内容。反馈问题时不要直接上传整个用户数据目录。

若点击软件“结束取点”，需要在 CAD 按 Enter 或 Esc 响应停止请求。软件收到结束回执后再继续编辑点表或切换项目。

## 导出和兼容性

- 普通导入的标注使用二维 E/N 布局；CAD 取点标注保留真实高程和手动位置，预览仍是俯视图。
- DXF 底图直接读取；DWG 借助本机可用转换工具或受限读取器。转换不等于所有专用对象都能完整预览。
- 部分含特殊视图样式或代理对象的 DWG，转换后的 DXF 可能无法在某些 CAD 环境正常重开。优先在 CAD 保存 DWG，需要交换 DXF 时另存并核对。
- 图纸缺少中文字体时使用系统替代字体，字宽和排版可能不同；本项目不附带商业字体。
- 图片、外部参照和底图依赖文件不自动打包到 DXF 内。移动导出图纸时需要一起携带，并核对引用路径。
- 软件不会自动保存 CAD 原图。所有实际取点标注是否写入图纸，由用户在 CAD 中保存决定。
